# rust32-playground
Personal repo for experiments with embedded Rust in an ESP32 microcontroller.

I'll be following examples from [impl Rust for ESP32](https://esp32.implrust.com/) as well as [The Rust on ESP Book](https://docs.espressif.com/projects/rust/book/) and hopefully move on to some personal projects (although those might earn their own repos) while loosely documenting my progress through the commit history.
